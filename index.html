Instalación

Tres pasos y verificación

Descarga, comprueba el hash y ejecuta. Elige tu distribución en las pestañas.

# comprueba el hash sha256sum picosoft-exsel-0.5.0-linux-x86_64.deb # instala sudo apt install ./picosoft-exsel-0.5.0-linux-x86_64.deb # lanza con un libro de ejemplo picosoft-exsel --sample sales
sha256sum picosoft-exsel-0.5.0-linux-x86_64.rpm sudo rpm -i picosoft-exsel-0.5.0-linux-x86_64.rpm picosoft-exsel --sample sales
chmod +x picosoft-exsel-0.5.0-linux-x86_64.AppImage ./picosoft-exsel-0.5.0-linux-x86_64.AppImage --sample sales
flatpak install --user ./picosoft-exsel-0.5.0-linux-x86_64.flatpak flatpak run ai.picosoft.exsel --sample sales

Antes de instalar

Linux x86_64 con glibc 2.35 o superior (Ubuntu 22.04, Debian 12, Fedora 36 o más reciente). Las 64 bits son la única arquitectura publicada en esta versión.

Cada instalador tiene su SHA-256 publicado en esta página y en el release de GitHub. Ejecuta sha256sum <archivo> y compáralo con el hash listado: deben coincidir letra por letra.

XLSX (su formato nativo), XLSM, XLSB, ODS, CSV y TXT. Guarda en XLSX sin convertir, conservando fórmulas, estilos, gráficos y formato condicional.
