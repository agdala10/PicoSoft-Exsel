PicoSoft-Exsel es una hoja de cálculo escrita en Rust: arranca en un instante, abre .xlsx sin convertirlos y funciona entera en tu equipo. Sin cuentas, sin telemetría, sin suscripción.

Descarga

Cuatro paquetes, el mismo programa. Elige el de tu distribución.

.deb

Debian · Ubuntu · Linux Mint · elementary

sudo apt install ./picosoft-exsel-0.5.0-linux-x86_64.deb 23,1 MB

.rpm

Fedora · RHEL · openSUSE · Mageia

sudo rpm -i picosoft-exsel-0.5.0-linux-x86_64.rpm 24,1 MB

.AppImage

Cualquier distro · sin instalación

chmod +x *.AppImage && ./picosoft-exsel-0.5.0-linux-x86_64.AppImage 20,7 MB

.flatpak

Flatpak · aislamiento por sandbox

flatpak install --user ./picosoft-exsel-0.5.0-linux-x86_64.flatpak 15,4 MB

Requisitos: glibc ≥ 2.35 (Ubuntu 22.04 o superior) · ID de aplicación ai.picosoft.exsel · paquetes firmados con hash SHA-256 publicados en el release.

Qué hace

Hojas de cálculo serias, sin pedirte permiso para nada.

513 funciones

Matemáticas, de texto, de fecha, lógicas, financieras y de búsqueda. 504 ya funcionan igual que en la hoja de cálculo de referencia.

Gráficos de verdad

Barras, líneas, dispersión, circular, combinados y paneles de control, con formato, series y ejes editables.

XLSX nativo

El formato abierto es su formato. Abre lo que te mandan y guárdalo sin perder fórmulas, estilos ni gráficos. También .ods y .csv.

Todo es un comando

274 comandos con atajos: desde la cinta, la terminal (picosoft-exsel-cli), el canal de control o MCP. Tus agentes pueden operarla entera.

12 idiomas

Interfaz, funciones y formatos numéricos localizados: español, inglés, chino, japonés, coreano, ruso, portugués, checo…

Rápida y discreta

Sin proceso de fondo, sin cuenta, sin telemetría. Arranca en caliente y se queda donde la dejaste.

Instalación y verificación

Comprueba el checksum antes de instalar: cada archivo tiene su hash en el release.

# 1. descargas el paquete desde la página de Releases y lo verificas
sha256sum picosoft-exsel-0.5.0-linux-x86_64.deb
# 3f10fe0f47b249fa56a9d29d83be0d48239b92cb091c233a51de700d98358445  picosoft-exsel-0.5.0-linux-x86_64.deb

# 2. lo instalas
sudo apt install ./picosoft-exsel-0.5.0-linux-x86_64.deb     # Debian/Ubuntu
sudo rpm -i picosoft-exsel-0.5.0-linux-x86_64.rpm            # Fedora/openSUSE
./picosoft-exsel-0.5.0-linux-x86_64.AppImage                 # cualquier distro
flatpak install --user ./picosoft-exsel-0.5.0-linux-x86_64.flatpak

# 3. lanzas
picosoft-exsel --sample sales
